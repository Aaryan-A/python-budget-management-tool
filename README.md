# Python Budget Management Tool

A Python application that helps users track expenses, calculate their remaining budget, and plan savings goals through a graphical user interface built with Tkinter.

## Features

- **Expense Tracking:** Add expenses with a name and amount.
- **Total Expenses:** Automatically calculates the sum of all recorded expenses.
- **Budget Calculation:** Calculates the remaining budget after expenses are deducted from yearly income.
- **Savings Goal Planning:** Estimates the money remaining after setting a savings goal.
- **Input Validation:** Displays error messages for missing or invalid inputs and prevents negative income, expenses, and savings goals.
- **Graphical User Interface:** Provides input fields, buttons, and a list of expenses using Tkinter.

## Technologies Used

- Python
- Tkinter
- Lists and Functions
- Conditional Statements
- Exception Handling
- Graphical User Interface (GUI) Development

## How to Run

1. Install Python 3 if it is not already installed.
2. Save the source code as `budget_management.py`.
3. Open a terminal in the folder containing the file.
4. Run:

   ```bash
   python budget_management.py
   ```

5. Enter your yearly income, add expenses, and optionally enter a savings goal.
6. Click **Calculate** to view your budget results.

**Note:** This application requires a desktop environment that supports Tkinter. Standard Google Colab sessions do not normally support opening its desktop GUI.
